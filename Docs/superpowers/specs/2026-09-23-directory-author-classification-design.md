# 目标目录理解与作者归档设计

## 目标

以资料库已有作品的目录结构、命名模式和代表内容改善分类，特别是同人志进入正确分类目录并按作者归档。资料库少于一千部作品；首次深入分析，之后增量更新。自定义规则编辑留待下次。

## 目录分析

- 区分分类目录、作者容器、完整作品和待确认目录。图片作品内部项目不得成为目标目录。
- 覆盖全部作品名称及结构；每部最多读取五个分散代表页。保存命名结构、频率、内容特征、样本来源和分析覆盖情况。
- 用户可修改目录用途、排除错误样本、指定参考作品；人工纠正优先。分析可暂停、恢复、增量更新，并显示无法读取的项目。
- 图像模型沿用现有可选下载机制；未安装时仍使用名称、结构、文本和 OCR。分析在本机进行。

## 分类及作者

- 现有明确规则优先。普通文件格式不得提前终止分类；分类展示候选、支持样本与理由。分类不能要求逐个确认概念标签。
- 识别社团、个人作者、作品标题、翻译和版本标签。个人作者优先，社团仅为辅助；同社团、相似图片或模糊跨语言名称不自动合并作者。
- 保存作者身份、日英文名、别名、来源及首选归档目录。用户可主动用浏览器搜索作者或社团名称，并确认对应关系。
- 复用已有作者目录；新目录采用 `[社团] 日文名 (英文名)`，缺失字段省略。确定属于某分类但作者不明确时建议放分类根目录。
- 明确建议可批量接受；作者歧义、新目录和类别不明项目单独审核。所有实际移动最终统一确认。

## 操作与范围

- 默认整理收件箱新文件。遇到“作者／多部作品”时，按完整作品归位，内部文件不拆散。
- “整理已有作品”是独立入口，仅处理用户明确选中的作品。已有作者目录不改名、不合并；整理后原有空目录不删除。
- 扩展不可变计划以支持在分类目录下创建作者目录和移动所选库内作品。保留同卷、无覆盖、预检、历史、崩溃恢复和撤销。
- 目录角色、说明或作者绑定变化后，受影响的未执行计划失效并重新审核。旧计划继续遵守原来源限制。

## 验收

- 至少 50 项独立样本，建议 30 项类别明确的同人志和 20 项易混淆的其他项目，不参与学习与调参。
- 明确同人志首选分类正确率至少 95%，其中至少 80% 进入可批量接受建议组；验收集中默认纳入方案的明确建议不得错分。
- 覆盖无图像模型、跨语言作者、多作者、文件变化、暂停恢复、迁移、库内来源限制及撤销。
